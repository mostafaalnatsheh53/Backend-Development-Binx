# Async/Await & Concurrency Basics Lab

## Overview

This project demonstrates the fundamentals of asynchronous programming in C# using the Task-based Asynchronous Pattern (TAP). It compares sequential and concurrent execution, measures execution time, and demonstrates task cancellation using `CancellationToken`.

## Features

- Task-based Asynchronous Programming (TAP)
- Sequential async execution
- Concurrent execution with `Task.WhenAll`
- Performance comparison using `Stopwatch`
- Task cancellation with `CancellationToken`

## Technologies

- C#
- .NET
- Async/Await
- Task Parallel Library (TPL)

## Learning Objectives

- Understand the Task-based Asynchronous Pattern.
- Use `async` and `await` correctly.
- Compare sequential and concurrent asynchronous execution.
- Improve performance with `Task.WhenAll`.
- Cancel asynchronous operations using `CancellationToken`.

## Output

The application demonstrates:

- Sequential execution time
- Concurrent execution time
- Cancellation of a long-running task
