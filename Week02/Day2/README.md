# LINQ Hands-On Lab

## Overview
This project demonstrates several core LINQ operations in C# using a simple Customer and Order domain.

## Features

### 1. GroupBy
Groups orders by customer and calculates the total order amount for each customer.

### 2. Join
Joins the Customer collection with the Order collection to display each customer's name alongside their order amount.

### 3. SelectMany
Flattens nested order collections from all customers into a single sequence.

### 4. Deferred Execution
Demonstrates how LINQ queries are executed only when enumerated by modifying the source collection after defining the query.

## Technologies
- C#
- .NET
- LINQ

## Learning Objectives
- Understand grouping with `GroupBy`.
- Combine collections using `Join`.
- Flatten nested collections using `SelectMany`.
- Understand deferred execution in LINQ.
